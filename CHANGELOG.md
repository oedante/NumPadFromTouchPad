# CHANGELOG

## 2.0.0 — объединение NumMac и Touchpad (2026-10-11)

Основа — рабочий конвейер Raw Input старого проекта NumMac; идея конструктора — из проекта Touchpad. Подробности причин — в `AUDIT.md`.

### Исправлено
- **Повторное нажатие той же клавиши** не срабатывало или срабатывало через раз. Причины: не читался Tip Switch (отрыв пальца не распознавался), «разблокировка» зависела от появления контакта с координатами (0,0) и опроса таймером 50 мс. Заменено конечным автоматом по Contact ID: каждое касание = одно логическое нажатие, KeyDown при касании, KeyUp при отрыве, независимо от координат.
- Быстрые нажатия (< 50 мс) больше не теряются; таймер-разблокировщик удалён.
- Аварийное завершение при пустом списке контактов (`contacts[0]`).
- Зоны клавиш были квадратными (ширина = высота) — неверное распознавание «0» и «Enter».
- Цифровой блок генерировал клавиши основного ряда (`VK_0`, `OEM_COMMA`, `Shift+=`); теперь `VK_NUMPAD*`, `VK_DECIMAL`, `VK_ADD`, Numpad Enter с флагом extended и правильными скан-кодами.
- Гибридный режим PTP (контакты в нескольких отчётах) и несколько отчётов в одном `WM_INPUT` обрабатываются корректно.
- Иконка трея загружалась относительно текущего каталога (падение при автозапуске); иконка оставалась в трее после выхода.
- Горячая клавиша `Ctrl+Space` (конфликт с IME) заменена настраиваемой, по умолчанию `Ctrl+Alt+N`; ошибка регистрации показывается пользователю.
- Некорректный ввод в полях настроек больше не роняет приложение; повреждённые файлы настроек откладываются, загружаются значения по умолчанию.
- Конструктор: залипание перетаскиваемой клавиши при отпускании над занятой ячейкой, сдвиг привязки широких клавиш, неподключённые кнопки «Загрузить/Сохранить».

### Добавлено
- Библиотека `NumPad.Core` (без Windows API): автомат нажатий, раскладки, hit-testing, калибровка, конфигурация, хоткеи — с тестами xUnit.
- Удержание клавиш, автоповтор, мультитач с подсчётом ссылок, модификаторы на тачпаде (Shift/Ctrl), сочетания (Ctrl+C), ввод текста.
- Режим срабатывания «при отпускании», поведение при соскальзывании пальца, учёт Num Lock, игнор ладони (Confidence).
- Сторож зависших контактов и повтор неотправленного KeyUp.
- Отпускание всех клавиш при выключении режима, смене раскладки, блокировке, сне, отключении устройства, выходе и необработанном исключении; отпускание модификаторов после аварийного завершения.
- Подавление курсора в режиме NumPad (`WH_MOUSE_LL`, пока палец на клавишах) и отключение тапов/прокрутки на Windows 11 24H2+ с гарантированным восстановлением.
- Раскладки в JSON: встроенные NUM10, NUM20, NUM30; визуальный редактор (перемещение, размер, сетка, промежуток, назначение, подписи, отключение зон, отмена/повтор, импорт/экспорт, возврат к стандартной), валидация.
- Мастер калибровки по пяти опорным клавишам (аффинное преобразование МНК), проверка «вхолостую», ручные границы, профили по устройствам.
- Новый интерфейс: главная, раскладки, калибровка, настройки, диагностика; трей с выбором раскладки; один экземпляр; автозапуск.
- Технический журнал без записи нажимаемых клавиш.
- Профили публикации win-x64 и win-arm64, CI на GitHub Actions.
- Прототип macOS-бэкенда (не проверен).

### Удалено
- Зависимость `InputSimulator 1.0.4` (заменена прямым `SendInput`).
- 156 параметров `Properties.Settings` (заменены JSON-раскладкой и профилями).
