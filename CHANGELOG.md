# CHANGELOG

## 3.0.0-beta1 — первая бета: редактор, родной вид на каждой ОС, открытый код (2026-10-19)

Первая бета-версия. Включает промежуточную сборку 3.0.0-alpha3 (редактор раскладок, новый значок) и всё, что сделано после неё. На ноутбуке с Windows программа проверена автором; на Linux и macOS она собирается и проходит самопроверку в CI, но на реальных устройствах ещё не проверялась — сообщения о проблемах приветствуются.

### Изменено
- **Родной вид на каждой ОС.** Системный шрифт (Segoe UI Variable в Windows, San Francisco в macOS, шрифт системы в Linux — проверяется в CI и показывается в «Диагностике»); светлая и тёмная тема и акцентный цвет — из настроек системы, при переключении темы окно перестраивается сразу. Цвета и боковая панель — в духе системы: Windows 11 (пункт со скруглением и акцентной полоской), macOS (выделение акцентным цветом, кегль 13), GNOME (скругление 6, серое выделение). Порядок кнопок в диалогах: в Windows основная кнопка слева, в macOS и GNOME — справа; Enter и Esc работают.
- **macOS:** меню программы в строке меню («О программе», «Настройки… ⌘,»), ⌘W закрывает окно, сочетания в подсказках — символами (⌘Z, ⇧⌘Z, ⌥, ⌫), горячая клавиша — как в меню (⌃⌥N), значок в строке меню — шаблон, который система красит под светлую/тёмную тему; кнопки «Выход» в окне нет (⌘Q и меню).
- **Настройки применяются сразу**, без кнопки «Сохранить» — как в системных настройках Windows 11 и macOS. Ctrl+, (⌘, в macOS) открывает настройки.
- Основные кнопки — акцентным цветом системы вместо жёлтого.
- **Редактор раскладок**: размер клавиши меняется за любой край или угол (раньше — только за маленький уголок справа снизу), курсор показывает, что будет изменено. Клавиши «прилипают» к краям и центрам соседних клавиш, к промежутку раскладки между соседями, к краям области, к размеру других клавиш и к сетке 2,5 %; направляющие показывают, к чему прилипла клавиша, клавиши того же размера подсвечиваются. Во время перетаскивания — подсказка с положением или размером (в % и в мм, если тачпад сообщает размер); линейки сверху и слева. Alt — без привязки, Shift — по одной оси, Alt+стрелки — размер, двойной щелчок — правка подписи. Щелчок без сдвига больше не создаёт шаг отмены.
- Подписи клавиш подбирают размер шрифта под клавишу и переносятся только по пробелу («Page Up»), а не посреди слова («Ente/r»).
- Панель редактора: инструменты — значками с подсказками, действия с раскладкой — в меню «Действия», пропорции, промежуток и «Вне клавиш — курсор» — на боковой панели; ничего не переносится в два ряда.
- Главная: без прокрутки, предпросмотр занимает свободное место; карточки устройства и раскладки шире; горячая клавиша — в виде клавиши.
- Длинные названия в выпадающих списках обрезаются многоточием (полный текст — в подсказке).
- Боковая панель: значки разделов, текст по центру пункта, горячая клавиша — отдельной «клавишей».
- Диагностика: заголовки и журнал переносятся по словам.
- Имя тачпада, если драйвер его не сообщает: по производителю («Apple Precision Touchpad» вместо «Precision Touchpad (VID_05AC&PID_0340)»).
- При смене языка без перезапуска на новый язык переходят и названия встроенных раскладок, и сообщения платформы: нет доступа к устройству, ошибка горячей клавиши и т. п. (`L.Retranslate`).

### Добавлено
- **Открытый код под лицензией MIT** (`LICENSE`), `CONTRIBUTING.md`; в настройках — карточка «О программе» с версией, лицензией и ссылками на GitHub. В `DISTRIBUTION.md` — бесплатная подпись для открытых проектов через SignPath Foundation.
- Снимки интерфейса в CI — на всех трёх ОС, в светлой и тёмной теме (ветки `screenshots-windows`, `-macos`, `-linux`).
- **Новый значок** (цифровой блок и лиса в пламени): программа, трей (на Windows — ICO со всеми размерами, отдельный упрощённый рисунок для 16–32 px), пакет MSIX, `.app` для macOS (`AppIcon.icns`), ярлык Linux. Все значки собираются скриптом `packaging/icons/make-icons.py` из исходного рисунка.
- `LayoutSnapper` — логика привязки в ядре с тестами (9); тесты имён тачпадов по производителю (4), перевода сообщений при смене языка (1) — всего 116.
- Самопроверка CI делает снимки всех страниц на обоих языках, с выделенной и перетаскиваемой клавишей и уведомлением; снимки публикуются в ветку `screenshots`.
- `THIRD-PARTY-NOTICES.md` (значки Material Design — Apache 2.0).

## 3.0.0-alpha2 — Ogneliss NumTouch (2026-10-17)

### Изменено
- Проект переименован в **Ogneliss NumTouch**: исполняемый файл `OgnelissNumTouch`, проекты и пространства имён `Ogneliss.NumTouch.*`, идентификатор пакета macOS `ru.ogneliss.numtouch`, папка данных `OgnelissNumTouch`, журнал `numtouch.log`.
- Настройки и раскладки прежней версии переносятся автоматически (копированием; старая папка не изменяется); записи автозапуска старой версии удаляются.
- macOS: управляемый код в одном файле, нативные библиотеки — рядом в `Contents/MacOS`, чтобы каждую можно было подписать Developer ID (требование нотаризации).
- Журнал пишется по-английски.

### Добавлено
- **Интерфейс на русском и английском**: язык системы или выбранный в настройках; при смене языка окно и меню трея перестраиваются без перезапуска. Тесты проверяют полноту перевода по исходникам.
- **Уведомление о смене режима**: плашка внизу экрана на ~2 с (NumPad вкл/выкл, тачпад не найден, выключение при блокировке/сне/ошибке); не забирает фокус; отключается в настройках. Работает одинаково на Windows, Linux и macOS.
- README на английском и русском.
- [DISTRIBUTION.md](DISTRIBUTION.md): подпись и публикация для каждой платформы — Developer ID и нотаризация (macOS), Microsoft Store / OV-сертификат / Azure Artifact Signing (Windows), контрольные суммы (Linux).
- Пакет **MSIX** для Microsoft Store (`packaging/windows`), автозапуск в пакете — через задачу StartupTask.
- CI: подпись Windows через Azure Artifact Signing, подпись Developer ID и нотаризация macOS — включаются при наличии секретов, только на `main`; `SHA256SUMS.txt` в релизе; самопроверка покрывает оба языка и уведомление.
- Тесты: локализация (7), перенос настроек (1) — всего 102.

## 3.0.0-alpha1 — Avalonia: Windows, Linux, macOS (2026-10-17)

### Изменено
- Интерфейс переписан с WPF на **Avalonia 11**: один код для Windows, Linux и macOS. Те же пять экранов (главная, раскладки, калибровка, настройки, диагностика), трей с выбором раскладки, диалоги, самопроверка `--selftest`.
- Проект переведён на **.NET 10 LTS** (поддержка .NET 8 заканчивается в ноябре 2026).
- Всё платформенное вынесено за интерфейсы `NumPad.Platform` (тачпад, вывод клавиш, блокировка курсора, горячая клавиша, жесты, автозапуск, системные события); реализация выбирается во время выполнения.
- Windows: Raw Input, горячая клавиша и низкоуровневый хук работают в отдельном потоке ввода со скрытым окном — блокировка курсора больше не зависит от загрузки интерфейса. Блокировка и сон отслеживаются через WTS и WM_POWERBROADCAST.
- Сборка кадров Precision Touchpad вынесена в `HidFrameAssembler` и покрыта тестами на всех ОС.

### Добавлено
- **Linux**: касания через evdev (любой тачпад с мультитачем), виртуальная клавиатура и мышь через uinput (X11 и Wayland), захват тачпада на время режима, проброс «зоны трекпада» NUM10 в курсор (с тапом и физическим щелчком), горячая клавиша через evdev, автозапуск XDG, `install.sh` с правилом udev.
- **macOS** (прототип на C#): MultitouchSupport, CGEventPost с флагом цифрового блока, Carbon-хоткей, CGEventTap, LaunchAgent, сборка `.app`.
- Таблицы кодов клавиш для Linux и macOS; предупреждение в редакторе о клавишах, недоступных на текущей ОС.
- Тесты: сборка кадров PTP, декодер evdev (включая повторное нажатие через декодер и движок), полнота таблиц кодов — 89 тестов, прогоняются на Windows, Linux и macOS.
- CI: матрица из трёх ОС, публикация шести сборок (win/linux/osx × x64/arm64), UI-самопроверка, пакеты `.exe`, `.tar.gz`, `.app.zip`, создание pre-release.

### Безопасность
- Транзитивная зависимость `Tmds.DBus.Protocol` поднята до 0.21.3 (GHSA-xrw6-gwf8-vvr9).

### Удалено
- WPF-приложение (остаётся в истории и в релизе v2.0.0-rc1) и Swift-прототип (заменён C#-бэкендом).
- Всплывающие уведомления о смене режима (в Avalonia нет кроссплатформенного API): состояние показывают значок и подсказка трея. *(Возвращены в 3.0.0-alpha2 в виде собственного экранного уведомления.)*

## 2.0.0 — объединение NumMac и Touchpad (2026-10-11)

Основа — рабочий конвейер Raw Input старого проекта NumMac; идея конструктора — из проекта Touchpad. Подробности причин — в `AUDIT.md`.

### Исправлено
- **Повторное нажатие той же клавиши** не срабатывало или срабатывало через раз. Причины: не читался Tip Switch (отрыв пальца не распознавался), «разблокировка» зависела от появления контакта с координатами (0,0) и опроса таймером 50 мс. Заменено конечным автоматом по Contact ID: каждое касание = одно логическое нажатие, KeyDown при касании, KeyUp при отрыве, независимо от координат.
- Быстрые нажатия (< 50 мс) больше не теряются; таймер-разблокировщик удалён.
- Аварийное завершение при пустом списке контактов (`contacts[0]`).
- Зоны клавиш были квадратными (ширина = высота) — неверное распознавание «0» и «Enter».
- Цифровой блок генерировал клавиши основного ряда (`VK_0`, `OEM_COMMA`, `Shift+=`); теперь `VK_NUMPAD*`, `VK_DECIMAL`, `VK_ADD`, Numpad Enter с флагом extended и правильными скан-кодами.
- Гибридный режим PTP (контакты в нескольких отчётах) и несколько отчётов в одном `WM_INPUT` обрабатываются корректно.
- Иконка трея загружалась относительно текущего каталога (падение при автозапуске); иконка оставалась в трее после выхода.
- Горячая клавиша `Ctrl+Space` (конфликт с IME) заменена настраиваемой, по умолчанию `Ctrl+Alt+N`; ошибка регистрации показывается пользователю.
- Некорректный ввод в полях настроек больше не роняет приложение; повреждённые файлы настроек откладываются, загружаются значения по умолчанию.
- Конструктор: залипание перетаскиваемой клавиши при отпускании над занятой ячейкой, сдвиг привязки широких клавиш, неподключённые кнопки «Загрузить/Сохранить».

### Добавлено
- Библиотека `NumPad.Core` (без Windows API): автомат нажатий, раскладки, hit-testing, калибровка, конфигурация, хоткеи — с тестами xUnit.
- Удержание клавиш, автоповтор, мультитач с подсчётом ссылок, модификаторы на тачпаде (Shift/Ctrl), сочетания (Ctrl+C), ввод текста.
- Режим срабатывания «при отпускании», поведение при соскальзывании пальца, учёт Num Lock, игнор ладони (Confidence).
- Сторож зависших контактов и повтор неотправленного KeyUp.
- Отпускание всех клавиш при выключении режима, смене раскладки, блокировке, сне, отключении устройства, выходе и необработанном исключении; отпускание модификаторов после аварийного завершения.
- Подавление курсора в режиме NumPad (`WH_MOUSE_LL`, пока палец на клавишах) и отключение тапов/прокрутки на Windows 11 24H2+ с гарантированным восстановлением.
- Раскладки в JSON: встроенные NUM10, NUM20, NUM30; визуальный редактор (перемещение, размер, сетка, промежуток, назначение, подписи, отключение зон, отмена/повтор, импорт/экспорт, возврат к стандартной), валидация.
- Мастер калибровки по пяти опорным клавишам (аффинное преобразование МНК), проверка «вхолостую», ручные границы, профили по устройствам.
- Новый интерфейс: главная, раскладки, калибровка, настройки, диагностика; трей с выбором раскладки; один экземпляр; автозапуск.
- Технический журнал без записи нажимаемых клавиш.
- Профили публикации win-x64 и win-arm64, CI на GitHub Actions.
- Прототип macOS-бэкенда (не проверен).

### Удалено
- Зависимость `InputSimulator 1.0.4` (заменена прямым `SendInput`).
- 156 параметров `Properties.Settings` (заменены JSON-раскладкой и профилями).
