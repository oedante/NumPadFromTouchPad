# ARCHITECTURE.md

## Стек

C# / **.NET 10 (LTS)** / **Avalonia 11** — один код интерфейса для Windows, Linux и macOS. Всё платформенное (касания, вывод клавиш, блокировка курсора, горячая клавиша, автозапуск) — за интерфейсами `Ogneliss.NumTouch.Platform`; реализация выбирается во время выполнения (`PlatformFactory`).

История: 2.0 — WPF только для Windows (тег `v2.0.0-rc1`); 3.0 — переход на Avalonia, общий платформенный слой, бэкенды Linux и macOS.

## Структура решения

```
OgnelissNumTouch.sln
├─ src/Ogneliss.NumTouch.Core              — логика без ОС: автомат нажатий, раскладки, hit-testing, калибровка, настройки, коды клавиш
├─ src/Ogneliss.NumTouch.Platform          — интерфейсы платформы, монотонные часы, сборка кадров PTP, заглушка NullPlatform
├─ src/Ogneliss.NumTouch.Platform.Windows  — Raw Input (PTP), SendInput, RegisterHotKey, WH_MOUSE_LL, SPI тачпада, реестр
├─ src/Ogneliss.NumTouch.Platform.Linux    — evdev (тачпад, клавиатуры), uinput (клавиши, курсор), EVIOCGRAB, XDG autostart
├─ src/Ogneliss.NumTouch.Platform.MacOS    — MultitouchSupport, CGEvent, Carbon hotkey, CGEventTap, LaunchAgent (прототип)
├─ src/Ogneliss.NumTouch.App               — Avalonia: окно, 5 страниц, трей, уведомление о смене режима, контроллер
├─ tests/Ogneliss.NumTouch.Tests           — xUnit: ядро, платформенная логика без ввода-вывода, полнота перевода (на 3 ОС в CI)
└─ packaging/                              — linux: udev-правило, .desktop, install.sh; macos: .app, подпись, нотаризация; windows: MSIX
```

## Интерфейсы платформы (`Ogneliss.NumTouch.Platform/Abstractions.cs`)

| Интерфейс | Windows | Linux | macOS |
|---|---|---|---|
| `ITouchpadBackend` | Raw Input, HID-коллекция 0x0D/0x05 (только Precision Touchpad) | `/dev/input/eventN`, протокол multitouch B (любой тачпад с драйвером ядра) | `MultitouchSupport.framework` (приватный) |
| `IKeyboardOutput` | `SendInput` VK + скан-код + extended | виртуальная клавиатура `/dev/uinput` | `CGEventPost` + флаг NumericPad |
| `IPointerSuppressor` | `WH_MOUSE_LL` пока палец на клавишах + хвост | `EVIOCGRAB` (захват тачпада) + виртуальная мышь для «зоны трекпада» | `CGEventTap` пока палец на клавишах + хвост |
| `IGlobalHotkey` | `RegisterHotKey` (перехватывается) | чтение клавиатур evdev (не перехватывается) | Carbon `RegisterEventHotKey` |
| `IGestureGuard` | `SPI_SETTOUCHPADPARAMETERS` (Win 11 24H2+) | — (захват и так отключает жесты) | — |
| `IAutostart` | `HKCU\…\Run` | `~/.config/autostart/*.desktop` | `~/Library/LaunchAgents/*.plist` |
| `SystemEvent` | блокировка (WTS), сон (WM_POWERBROADCAST) | — (сторож движка) | — (сторож движка) |

Потоки: Windows — отдельный поток ввода со скрытым окном (Raw Input, хоткей и LL-хук не зависят от загрузки UI); Linux — поток чтения на каждое устройство; macOS — поток MultitouchSupport. Контроллер переводит события в UI-поток Avalonia; движок работает только в UI-потоке. Решение «блокировать указатель» хук читает из `volatile`-полей, которые контроллер обновляет после каждого кадра.

## Поток данных

```
бэкенд (поток ввода) ─► TouchFrame (норм. 0..1) ─► Dispatcher.UIThread ─► ModeManager ─► KeyPressEngine ─► IKeyboardOutput
                                                                    │                     └► ReportTouchState ─► IPointerSuppressor
                                                                    └► FrameArrived ─► страницы (предпросмотр, редактор, калибровка, диагностика)
DispatcherTimer 10 мс ─► Engine.Tick (автоповтор, сторож, повтор KeyUp)
```

## Модель состояний (центральное исправление дефекта повторных нажатий)

1. **Физическое касание** — `TouchContact{Id, X, Y, Tip, Confidence}` в кадре.
2. **Логическое нажатие** — состояние контакта в движке: зона фиксируется в момент касания, живёт до отрыва этого Contact ID (Tip = 0, исчезновение из полного кадра или сторож).
3. **Системное событие** — `KeyDown/KeyUp` через счётчик ссылок на клавишу.

Политики: срабатывание при касании / при отпускании; удержание или отпускание при соскальзывании; модификаторы удерживаются пальцем; ладонь игнорируется; сторож зависших контактов; `ReleaseAll` при выключении режима, смене раскладки, блокировке, сне, потере устройства, выходе, сбое.

## Координаты

Устройство: 0..1 по логическому диапазону (Y вниз). Наклейка: 0..1 области; калибровка — аффинное преобразование (6 параметров, МНК по 5 опорным клавишам) или ручной прямоугольник.

## Внешний вид по ОС

`Services/PlatformTheme.cs`: системный шрифт (`FontManagerOptions` в `Program.BuildAvaloniaApp`), кисти для светлой и тёмной темы по ОС (`ThemeDictionaries`), размеры (кегль 13 в macOS), моноширинный шрифт, порядок кнопок диалога, обозначения сочетаний (⌘ ⌥ ⇧ ⌃ в macOS). Тема и акцентный цвет — из ОС через FluentTheme (`RequestedThemeVariant="Default"`); в XAML всё, что зависит от темы, — `DynamicResource`. Стили конкретной ОС — по классу окна (`Window.win/.mac/.linux`). При смене темы системы окно пересоздаётся (как при смене языка), холст раскладки берёт цвета из ресурсов. macOS: меню программы (`MacMenu`), шаблонный значок в строке меню.

## Локализация

`Ogneliss.NumTouch.Core.Localization.L`: ключ — английский текст (`L.T`, `L.F` с `{0}`, `L.N` — пометка ключа без перевода для данных вроде названий клавиш), русская таблица `RussianStrings`; XAML — расширение разметки `{l:T '…'}` (значение берётся при загрузке). Язык — `AppSettings.Language` (Auto/English/Russian; Auto — русский для русской локали системы). При смене языка `L.Changed` → приложение перестраивает главное окно на той же странице и обновляет меню трея; встроенные раскладки пересоздаются с названиями на новом языке. Журнал — всегда английский.

## Редактор раскладок

`LayoutCanvas` (App) рисует наклейку и обрабатывает мышь: попадание в край или угол любой клавиши (допуск 7–11 px, у выделенной — приоритет), перемещение с порогом 3 px (щелчок не создаёт шаг отмены), Shift — одна ось, Alt — без привязки. Геометрию привязки считает `LayoutSnapper` (Core, без UI, с тестами): кандидаты по каждой оси — края и центры других клавиш, промежуток раскладки от соседей того же ряда/столбца, границы области, размер других клавиш (при изменении размера); сетка 2,5 % — только если рядом нет других кандидатов. Результат — новый прямоугольник, направляющие для отрисовки и клавиши того же размера.

## Уведомление о смене режима

`ModeNotifier` подписан на `AppController.ModeChanged` и показывает `OsdWindow` — окно без рамки, поверх остальных, `ShowActivated=false`, без кнопки в панели задач, внизу по центру рабочей области основного экрана; скрывается через 1,8 с или по щелчку. Своё окно вместо системных уведомлений: одинаково на трёх ОС, без разрешений и без записей в центре уведомлений. Ошибка оконной системы при показе только пишется в журнал.

## Сознательно не делаем

Собственный драйвер; MVVM-фреймворк и DI-контейнер (для 5 страниц избыточны); плагины на клавишах.
